# Logo Waby Soft — Panduan Pemakaian

Logo: huruf **W Fraunces** (font yang sama dengan web) + **titik hijau** — "W." Titiknya tanda bot aktif/online sekaligus aksen satu-satunya.

## Warna
- Ink (hitam tinta): `#16150F`
- Hijau WhatsApp (titik): `#25D366`
- Latar terang: Paper `#FBFAF7` / putih `#FFFFFF`
- Di latar gelap pakai varian putih; titik tetap hijau (atau putih polos untuk versi mono).

## File
- `waby-symbol.svg` — simbol W + titik hijau (utama). Varian: `-black` (satu warna), `-white` (di gelap), `-whitemono`, `-small` (versi gemuk untuk ukuran kecil).
- `waby-lockup.svg` — simbol + teks, horizontal (header web, kop dokumen). `-white` untuk gelap.
- `waby-lockup-stacked.svg` — tumpuk, untuk ruang persegi (cover, banner).
- `waby-wordmark.svg` — teks saja + titik hijau di akhir (seperti logo di navbar sekarang). `-white` untuk gelap.
- `png/` — versi PNG transparan resolusi besar dari semua file di atas.
- `web/` — paket ikon web siap pasang: `favicon.ico`, `favicon.svg`, PNG 16/32/48, `apple-touch-icon.png`, `icon-192/512`, `maskable-512`, `site.webmanifest`, dan `head-snippet.html` (salin isinya ke `<head>`). Ganti `/favicon.svg` lama di web dengan `web/favicon.svg`.

## Aturan singkat
- Ruang kosong di sekeliling logo: minimal selebar diameter titik hijau × 2.
- Ukuran minimum simbol: 16 px di layar (di bawah 24 px pakai `waby-symbol-small.svg`), 8 mm di cetak.
- Jangan: mengubah warna titik selain hijau/ink/putih, memutar/menarik logo, menambah bayangan/gradasi, mengganti font teks (selalu Fraunces), atau menaruh versi hitam di latar gelap.

## Catatan
Semua teks di file SVG sudah berupa outline (bukan font hidup), jadi tampil sama di mana pun tanpa perlu memasang font.
